1. 为什么要引入进程：程序并发执行

在单道批处理系统中，内存里只容纳一道程序，CPU 与外部设备串行工作，资源利用率很低。引入多道程序技术后，内存中可同时装入多道程序，让它们并发推进：当一道程序因等待 I/O 而暂停时，CPU 立即转去执行另一道程序，从而提高系统吞吐量。

但随之而来的问题是：这些并发执行的程序如何被操作系统描述、管理和调度？静态的「程序」只是一组有序指令和数据的集合，它既不能表达「哪道程序已调入内存、运行到哪一条指令」，也不能表达「它占用了哪些资源、当前处于何种状态」。因此操作系统必须引入一个新的概念来刻画程序的动态执行过程——这就是进程（Process）。

定义

进程是进程实体的运行过程，是系统进行资源分配和调度的一个独立单位。也可以表述为：进程是程序在一个数据集合上运行的过程，是系统进行资源分配和调度的基本单位。

理解这个定义要抓住两点：其一，进程是动态的，是程序的一次执行过程，有「生命期」（创建、就绪、运行、阻塞、终止）；其二，进程是操作系统分配资源的基本单位，同时也是早期系统中独立调度的单位（引入线程后，调度单位变为线程，这一点在第 2.1.5 节详述）。

2. 进程与程序的区别和联系

进程与程序「一字之差」，却是历年选择题的高频考点。核心区别可以概括为「静与动、永久与暂时」。

对比项程序（Program）进程（Process）
本质 静态的，是一组指令和数据的集合，是永久存在的 动态的，是程序的一次执行过程，是暂时存在的
存在时间 可以长期保存，与机器无关 有创建、活着、消亡的生命周期
能否并发 程序本身不能并发执行 多个进程可以并发执行
组成 只包含代码和数据 由 PCB、程序段、数据段 三部分组成
对应关系 一个程序可以对应多个进程 一个进程也可运行多个程序（尤其配合线程后更常见）
关键结论

① 程序是静态的，进程是动态的；② 程序可永久存在，进程只是暂时存在；③ 一个程序可以创建多个进程（例如多次双击运行同一个可执行文件），一个进程也可以执行多个程序（通过调用其它程序）；④ 进程 = 程序 + 数据 + PCB，而 PCB 是进程区别于程序的关键。

易错点

「进程是一个程序及其数据在机器上运行的过程」——强调的是过程，不是「程序实体」。另外，进程与程序的对应关系是多对多，不能说「进程就是程序」或「一个程序只能有一个进程」。

3. 进程的组成

一个进程实体（又称进程映像）由三部分构成：PCB（进程控制块）、程序段、数据段。其中 PCB 是进程存在的唯一标志，操作系统正是通过 PCB 来感知进程的存在。

3.1 程序段与数据段

  • 程序段：就是能被 CPU 执行的程序代码，它描述了进程要做的事；
  • 数据段：指程序运行时所需的数据（如全局变量、常量、工作区等），它描述了进程操作的对象。

从「静态」角度看，程序段和数据段也被合称为「程序」；但只有加上描述运行状态的 PCB，程序才真正成为一个可被操作系统管理的进程。

3.2 进程控制块 PCB（重点）

定义

进程控制块（Process Control Block, PCB）是操作系统为每个进程建立的数据结构，用于保存进程的描述信息、控制信息、资源清单以及处理机现场信息。操作系统通过 PCB 来管理和控制进程，PCB 是进程存在的唯一标志。

类别主要内容
进程描述信息进程标识符 PID、用户标识符 UID（谁拥有的进程）
进程控制和管理信息进程当前状态、进程优先级、代码运行入口、程序在外存中的地址、计时信息（已运行时间——CPU 时间片）
资源分配清单程序段指针、数据段指针、打开的文件列表、占用的 I/O 设备等
处理机相关信息各通用寄存器的值、程序计数器 PC、程序状态字 PSW 等（即处理机现场，用于进程切换后恢复运行）
关键结论：PCB 有什么用

① PCB 是进程存在的唯一标志——创建进程就是创建 PCB，撤销进程就是回收 PCB；② 操作系统将各进程的 PCB 组织成PCB 表（分就绪队列、阻塞队列等），通过链表或索引方式来调度进程；③ 进程切换时，必须保存当前进程的现场到其 PCB，再从新进程的 PCB 中恢复现场，这就是「上下文切换」。

记忆口诀

进程组成记「三件套」：程序段、数据段、PCB。再补一句「PCB 是唯一标志」——凡问「进程存在的唯一标志是什么」，答 PCB。

3.3 进程的组织方式

系统中同时存在许多进程，操作系统如何高效地找到「处于就绪状态、可以投入运行」的进程？答案是依靠对 PCB 的组织。操作系统把各个进程的 PCB 按状态组织起来，常用的方式有两种：

  • 链接方式：把处于同一状态的 PCB 用链接字链接成队列，例如就绪队列、若干个阻塞队列（按阻塞原因区分）。操作系统在内存中保存各队列的队首指针，调度时只需从就绪队列取队首进程。
  • 索引方式：根据进程状态建立若干张索引表（如就绪索引表、阻塞索引表），表中登记的是相应状态 PCB 的地址，操作系统维护各索引表在内存中的首地址。
关键结论

PCB 是常驻内存的，操作系统通过PCB 表（就绪队列、阻塞队列、索引表等）来组织和管理所有进程。进程切换时，调度程序从就绪队列中选出一个进程投入运行，将其从就绪队列摘下，并把被剥夺 CPU 的进程按其新状态插入相应队列。可见，「进程队列」实际上是「PCB 队列」。

需要强调的是，同一进程只有一个 PCB，因此一个 PCB 在同一时刻只能位于一个队列之中。进程控制块是操作系统对进程进行管理的唯一依据：创建进程时分配 PCB，撤销进程时回收 PCB；进程因等待某事件而暂停时，其 PCB 从就绪队列转入相应的阻塞队列，事件发生后又被重新插入就绪队列。理解了这一点，就不难理解下一节「进程的状态与转换」。

4. 进程的特征

与静态的程序相比，进程具有以下特征，其中动态性是最基本的特征：

  • 动态性：进程是程序的一次执行过程，有「创建——就绪——运行——阻塞——终止」的生命期。动态性是进程最基本的特征。
  • 并发性：多个进程实体可同时存在于内存中，并在宏观上并发执行。并发性是进程的重要特征，也是 OS 引入进程的目的之一。
  • 独立性：进程是一个能独立运行、独立获得资源、独立被调度的基本单位，是资源分配的基本单位。
  • 异步性：各进程按各自独立的、不可预知的速度向前推进，走走停停，何时执行、何时暂停不确定。
  • 结构性：进程实体由 PCB、程序段、数据段三部分组成，具有一定结构。
关键结论

五个特征中，动态性是最基本的（因为进程本质上是「过程」）；并发性是引入进程的直接目的；异步性是「进程以不可预知的速度推进」，是产生同步互斥问题的根源。

5. 本节小结与真题问法

记忆口诀

概念：进程是程序的一次执行过程，是资源分配和调度的基本单位。
区别：程序静、进程动；程序永久、进程暂时。
组成：程序段 + 数据段 + PCB（PCB 是唯一标志）。
特征：动态、并发、独立、异步、结构——「动并独异构」，动态性最基本。

真题典型问法

① 问「进程存在的唯一标志」→ 答 PCB（进程控制块）。
② 问「进程最基本的特征」→ 答 动态性。
③ 给若干说法判断对错，常见错误项：把进程说成「静态的」、把程序说成「动态的」、认为「一个程序只能对应一个进程」、把「程序段」等同于「整个进程实体」。

④ 问「进程与程序的本质区别」→ 进程是动态的、暂时的执行过程，程序是静态的、永久的指令集合。
⑤ 问「操作系统依靠什么感知进程的存在」→ 依靠 PCB；进程切换时需要保存/恢复处理机现场（存于 PCB）。

教材原文（王道）

进程是进程实体的运行过程，是系统进行资源分配和调度的一个独立单位。进程实体由程序段、数据段和 PCB 三部分组成，其中 PCB 是进程存在的唯一标志。进程具有动态性、并发性、独立性和异步性等特征，动态性是进程最基本的特征。
