1. 问题背景与模型

哲学家进餐问题由 Dijkstra 提出，是对并发进程竞争有限资源并可能死锁的经典抽象。5 位哲学家围坐在一张圆桌旁，桌上摆着 5 根筷子（或叉子），每两位哲学家之间一根。哲学家的生活只有两种状态：思考与进餐。进餐时，一位哲学家必须同时拿起左右两根筷子（缺一不可），进餐完毕把两根筷子放回原处继续思考。

定义

哲学家进餐问题：5 位哲学家与 5 根筷子围成一圈，第 i 位哲学家的左筷为 i、右筷为 (i+1) mod 5。每位哲学家只有同时持有左右两根筷子时才能进餐，且任一根筷子在同一时刻只能被一位哲学家持有。要求给出一个既满足互斥、又不会死锁的并发方案。

若把「哲学家」看成进程、「筷子」看成临界资源（各一根），本题本质上就是多个进程循环地申请多个资源的模型，是理解死锁成因与预防的最佳载体。

2. 错误解法：为什么会死锁

最直观的做法是给每根筷子设一个初值为 1 的信号量 chopstick[i]，所有哲学家都「先拿左、再拿右」：

semaphore chopstick[5] = {1, 1, 1, 1, 1};

philosopher(i) {
    while (1) {
        P(chopstick[i]);           // 先拿左筷
        P(chopstick[(i+1) % 5]);   // 再拿右筷
        eat;                       // 进餐
        V(chopstick[i]);           // 放下左筷
        V(chopstick[(i+1) % 5]);   // 放下右筷
        think;
    }
}

这个算法能保证筷子互斥，却存在死锁危险：若某一时刻 5 位哲学家同时都拿起了自己的左筷，则 5 根筷子已全被占用。此时每位哲学家都去申请右筷，而右筷恰好握在邻座手中，谁都拿不到，于是每个人都在等待邻座放下筷子，形成循环等待，永远僵持——死锁。

关键结论

死锁的产生源于循环等待：每人「请求并保持」一根筷子（左筷），又去「循环地」等待下一根（右筷）。这与死锁四个必要条件——互斥、请求与保持、不可剥夺、循环等待——完全吻合。要消除死锁，只需破坏其中任意一个条件。

3. 三种避免死锁的方案（重点）

方案做法破坏的死锁条件
① 限制人数 至多允许 4 位哲学家同时试图拿筷子（用初值 4 的信号量 count 控制） 破坏循环等待：5 人中至多 4 人抢筷，必然有人能拿到两根，不会全体僵持
② 一次性成对分配 仅当左右两筷都可用时才允许拿起；或用一把互斥锁把「拿两筷」做成原子操作 破坏请求与保持（AND 型信号量 / 模拟一次性申请全部资源）
③ 资源有序分配（奇偶法） 规定全局取筷顺序：奇数号哲学家先取右、再取左；偶数号哲学家先取左、再取右 破坏循环等待：所有进程按同一「序」申请资源，不可能构成环路
关键结论

本节的解题要义是：能证明死锁、并能用「破坏四个必要条件之一」的方式消除。方案 ③「奇偶法」最简洁、最常考，其本质是资源有序分配法——让每位哲学家都按「筷子编号的大小顺序」取筷（先小号后大号），使资源请求不构成环。

方案 ① 限制至多 4 人

semaphore chopstick[5] = {1, 1, 1, 1, 1};
semaphore count = 4;          // 至多 4 人同时取筷

philosopher(i) {
    while (1) {
        P(count);                     // 限制并发取筷的人数
        P(chopstick[i]);              // 拿左筷
        P(chopstick[(i+1) % 5]);      // 拿右筷
        eat;
        V(chopstick[i]);              // 放左筷
        V(chopstick[(i+1) % 5]);      // 放右筷
        V(count);
        think;
    }
}

方案 ③ 资源有序分配（奇偶法）

semaphore chopstick[5] = {1, 1, 1, 1, 1};

philosopher(i) {
    while (1) {
        if (i % 2 == 0) {             // 偶数号：先左后右
            P(chopstick[i]);
            P(chopstick[(i+1) % 5]);
        } else {                      // 奇数号：先右后左（破坏循环等待）
            P(chopstick[(i+1) % 5]);
            P(chopstick[i]);
        }
        eat;
        V(chopstick[i]);              // 放下筷子（先取的后放，后取的先放）
        V(chopstick[(i+1) % 5]);
        think;
    }
}
易错点

① 单纯给每根筷子一个初值 1 的信号量，并不能避免死锁——它只保证了互斥；是否死锁取决于取筷的顺序。
② 方案 ③ 的关键是「奇数号先右后左」（或让所有哲学家都先取编号小的筷子），目的不是改变资源本身，而是让资源请求不构成环。
③ 拿起与放下筷子的 P/V 必须成对，且放下顺序建议与拿起顺序相反（后取先放），避免悬空等待。
④ 方括号「破坏条件」不要张冠李戴：限制人数与有序分配都破坏循环等待；一次性成对分配破坏请求与保持。
⑤ 「思考」阶段不占用任何筷子，一定要在放下筷子后再思考。

4. 本节小结与真题问法

记忆口诀

一错：人人「先左后右」→ 循环等待死锁。
三法：①限制人数（≤4）；②成对一次取得（AND 型）；③资源有序分配（奇偶法）。
一对应：限制人数 / 有序分配 → 破坏循环等待；成对分配 → 破坏请求与保持。

真题典型问法

① 问「5 位哲学家都先拿左筷再拿右筷，是否可能死锁、为什么」→ 可能，因为会形成循环等待。
② 问「至少需要限制几人同时取筷才能避免死锁」→ 4 人（5 人中至多 4 人抢筷，必有人能凑齐两根）。
③ 给出若干修改方案，判断「哪种能避免死锁、破坏了哪个必要条件」。
④ 与死锁的四个必要条件结合：要求指出方案对应破坏了哪一个条件。
⑤ 变式：若改为 P 个哲学家、P 根筷子，或每根筷子需先编号再按序申请，问结论。

教材原文（王道）

哲学家进餐问题中，若不采取任何措施，5 位哲学家各自先拿起左边的筷子再试图拿起右边的筷子，则可能出现 5 人各自持有一根筷子并等待相邻者释放筷子的情形，即产生死锁。为防止死锁，可采用以下方法：允许至多 4 位哲学家同时拿筷子；仅当左右两根筷子均可用时才允许拿筷子；规定奇数号哲学家先拿左边再拿右边，偶数号哲学家先拿右边再拿左边。这些方法本质上都是通过破坏循环等待或请求与保持条件来避免死锁。
