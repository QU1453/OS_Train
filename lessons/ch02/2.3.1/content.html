2.3.1 同步与互斥的基本概念

进程具有并发和异步两个重要特征。当多个进程并发执行时，它们可能共享某些资源（变量、缓冲区、打印机等）。如果不加约束，多个进程对共享资源的交叉访问就会产生错误、结果不可再现。因此操作系统必须提供一种机制，对并发进程的执行次序和资源访问加以协调，这就是本节要讲的进程同步与进程互斥。

1. 进程同步（直接制约关系）

定义

进程同步（Synchronization）又称直接制约关系，是指为完成某种任务而建立的两个或多个进程，因需要在某些位置上协调它们的工作次序而产生的制约关系。进程间的直接制约关系源于它们之间的相互合作。

通俗地说，进程同步要解决的是「先后顺序」问题：某些操作必须在另一些操作之前（或之后）发生。例如：

  • 「计算进程」与「打印进程」：计算进程把结果放入缓冲区，打印进程才能从缓冲区取出打印——先「写」后「读」。
  • 生产者和消费者之间：生产者先把产品放入缓冲区，消费者才能取走——「先生产、后消费」。

同步是进程之间主动配合的结果，若没有这种次序协调，合作就无法正确完成。

2. 进程互斥（间接制约关系）

2.1 临界资源

定义

临界资源（Critical Resource）是指在一段时间内只允许一个进程使用的资源。例如打印机、绘图仪、摄像头等设备，以及许多共享变量、共享数据、内存缓冲区等。对临界资源的访问必须互斥地进行。

2.2 进程互斥

定义

进程互斥（Mutual Exclusion）又称间接制约关系，是指当一个进程正在访问某临界资源时，另一个想要访问该临界资源的进程必须等待；只有当前进程访问结束并释放该资源后，另一进程才能访问。

互斥与同步的区别：同步是「协调先后次序」，源于进程间的合作；互斥是「竞争使用独占资源」，源于进程对临界资源的争夺。因此同步是直接制约，互斥是间接制约。

易错点

「互斥」并不是让进程「完全串行」，而是在同一临界资源上串行：不同进程访问不同临界资源时互不影响；只有访问同一临界资源时才需要互斥。不要把互斥范围随意放大。

3. 临界区的四个组成部分

对临界资源的访问，在逻辑上可以分为四个部分（以访问临界资源的进程为例）：

部分作用说明
进入区 检查是否可进入临界区 若可进入，则设置「正在访问」标志（上锁），阻止其他进程同时进入
临界区 访问临界资源的那段代码 又称临界段，是真正读写共享资源的代码
退出区 解除「正在访问」标志 相当于「解锁」，让出对该临界资源的占用
剩余区 做其他处理 与临界资源访问无关的代码 
while (true) {
    // 进入区：上锁 / 检查
    entry_section();

    // 临界区：访问临界资源
    critical_section();

    // 退出区：解锁
    exit_section();

    // 剩余区
    remainder_section();
}
关键结论

进入区和退出区是负责实现互斥的代码；临界区是访问临界资源的代码段。也就是说，真正需要「一次只允许一个进程执行」的是临界区代码，而进入区/退出区是为保证这一点服务的。

4. 同步机制应遵循的四条准则

无论是软件方法还是硬件方法，凡是用来解决临界区互斥的同步机制，都应当遵循以下四条准则：

  1. 空闲让进。临界区空闲时，应允许一个请求进入临界区的进程立即进入，以提高资源利用率。
  2. 忙则等待。当已有进程进入临界区时，其他试图进入临界区的进程必须等待，以保证互斥。
  3. 有限等待。对请求访问的进程，应保证它能在有限时间内进入临界区，即不会「无限期等待」（避免饥饿）。
  4. 让权等待。当进程不能进入临界区时，应立即释放处理机，防止进程陷入「忙等待（busy waiting）」。
易错点 · 让权等待不是必须的

前三条「空闲让进、忙则等待、有限等待」是必须满足的基本准则；而让权等待往往难以实现，许多经典互斥方法（如软件方法中的单标志法、双标志先检查法等）并不满足让权等待，会出现忙等。考试中要能区分「哪些方法满足让权等待、哪些不满足」。

记忆口诀

同步：直接制约，讲「次序」，源于合作。

互斥：间接制约，讲「独占」，源于竞争。

临界区四部分：进入区、临界区、退出区、剩余区。

四条准则：空闲让进、忙则等待、有限等待、让权等待（口诀「空忙限让」）。

5. 本节小结与真题问法

真题典型问法

① 问「同步与互斥的制约关系」→ 同步是直接制约、互斥是间接制约。

② 问「临界区是指」→ 访问临界资源的那段代码（不是「临界资源本身」，也不是「进入区」）。

③ 问「同步机制应遵循的准则」→ 空闲让进、忙则等待、有限等待、让权等待；并要知道哪一条往往得不到满足（让权等待）。

④ 给出设备/变量判断是否为临界资源 → 一段时间内只允许一个进程使用的即为临界资源（如打印机、共享变量、缓冲区）。

教材原文（王道）

临界资源是指一个时间段内只允许一个进程使用的资源，各进程之间采取互斥方式，实现对临界资源的共享。同步机制应遵循的准则：空闲让进、忙则等待、有限等待、让权等待。
