1. 为什么要用「指标」衡量调度算法

调度算法决定「CPU 该分给哪个进程」。不同的算法会让作业「等多久、多久完成、系统效率多高」千差万别。为了客观衡量各种调度算法的好坏，需要一组评价指标。408 中常考的是周转时间、带权周转时间、等待时间、响应时间，以及系统的 CPU 利用率和吞吐量。

关键结论：面向用户 vs 面向系统

评价指标可分两类：
面向用户（关注进程体验）：周转时间、带权周转时间、等待时间、响应时间；
面向系统（关注整体效率）：CPU 利用率、系统吞吐量。

2. CPU 利用率

CPU 利用率衡量 CPU 有多「忙」：

CPU 利用率 = 忙碌（CPU 运行）时间 / 总时间

在多道程序系统中，当一道程序因 I/O 而等待时，可让另一道程序占用 CPU，从而提高 CPU 利用率。因此在设计调度算法时，希望尽量让 CPU 保持忙碌。

易错点

CPU 利用率还包括内核程序运行的时间，不只是用户程序。当系统完全空闲时，利用率最低（为 0）。

3. 系统吞吐量

吞吐量衡量系统在单位时间内「干完多少活」：

系统吞吐量 = 单位时间内完成的作业（进程）数

吞吐量越大，系统效率越高。但要注意：吞吐量与「周转时间小」并不总是一致——例如短作业会很快完成、提高吞吐量，但可能让长作业「饿死」，此时长作业的周转时间反而变大。

关键结论

吞吐量关注系统效率（完成的作业数量），而周转时间关注单个作业从提交到完成的时长，二者角度不同，不要混为一谈。

4. 周转时间与带权周转时间（重点、高频）

作业从被提交给系统，到完成并获得结果，所经历的全部时间称为周转时间。它由四部分构成：

定义

作业周转时间 = 作业完成时间 − 作业到达（提交）时间
等价地，周转时间 = 等待时间 + 处理机执行（服务）时间 + I/O 等待时间 等全部时间之和。

由于不同作业本身的「实际运行时间（服务时间）」长短不同，单看周转时间无法公平比较。于是引入带权周转时间（又称「带权周转时间」/「带权周转时间」）：

带权周转时间 = 作业周转时间 / 作业实际运行时间（服务时间）（≥ 1）

带权周转时间表示「周转时间是实际运行时间的多少倍」，越小越好。
对于整个作业序列，常计算平均周转时间与平均带权周转时间：

平均周转时间       = (Σ 各作业周转时间) / 作业数
平均带权周转时间   = (Σ 各作业带权周转时间) / 作业数
关键结论

① 带权周转时间恒 ≥ 1，等于 1 表示作业一到达就立即运行并连续运行到结束（没有任何等待）。
② 周转时间、带权周转时间都越小越好。
③ 做题时先画出作业的执行时间轴，标出每个作业的「开始时刻」和「完成时刻」，再套公式。

计算示例（顺序执行，非抢占）

设三个作业按给定顺序 A、B、C 依次执行：

作业到达时间服务时间开始时间完成时间周转时间带权周转时间
A070777/7 = 1.00
B2471111 − 2 = 99/4 = 2.25
C41111212 − 4 = 88/1 = 8.00

平均周转时间 = (7 + 9 + 8) / 3 = 24 / 3 = 8.0；平均带权周转时间 = (1.00 + 2.25 + 8.00) / 3 = 11.25 / 3 = 3.75。
注意：若「当前时间」小于某作业到达时间，则开始时间取二者较大者（CPU 会空闲等待它到达）。

5. 等待时间

等待时间是指进程在就绪队列中等待的时间（等待 CPU 的时间）（有的定义还包含在阻塞队列中等待 I/O 的时间）。对作业而言，常简化为：

作业等待时间 = 作业周转时间 − 服务时间 = 开始时间 − 到达时间
易错点

① 等待时间不包括作业自身的执行时间，只统计「等待」的部分。
② 调度算法只能影响等待时间（占用 CPU 前的等待），无法影响作业实际的运行时间和 I/O 时间。因此调度算法优化的核心目标就是缩短等待时间。

6. 响应时间

定义

响应时间 = 从用户提交请求（或作业到达）到系统首次产生响应所经历的时间。它强调「交互式系统中用户感受到的快慢」。

响应时间越短，用户感觉系统「反应越快」。分时/交互式系统特别关注响应时间，因此常采用时间片轮转等能保证及时响应的算法。

关键结论：四个时间指标的关系

① 周转时间：从提交到完成的全过程时间。
② 带权周转时间：周转时间 ÷ 服务时间，恒 ≥ 1。
③ 等待时间：周转时间中「等待」的那部分（周转时间 − 服务时间）。
④ 响应时间：从提交到首次响应的时间，通常比周转时间短。
注意：前三个的终点是「完成」，响应时间的终点是「第一次响应」，不要混淆。

7. 本节小结与真题问法

记忆口诀

周转 = 完成 − 到达；带权周转 = 周转 ÷ 服务（≥1）；等待 = 周转 − 服务；响应 = 首次响应 − 提交。四者皆越小越好；CPU 利用率、吞吐量越大越好。

真题典型问法

① 给出一组作业的到达时间与服务时间，某算法下的执行顺序，求平均周转时间与平均带权周转时间。
② 判断：「带权周转时间可能小于 1」→ 错误，恒 ≥ 1。
③ 问「调度算法能影响哪个指标」→ 主要是等待时间（以及由它决定的周转、带权周转、响应时间）。
④ 问「交互式系统最关注的指标」→ 响应时间。

教材原文（王道）

周转时间是指从作业被提交给系统开始，到作业完成为止的这段时间间隔。带权周转时间是指作业周转时间与作业实际运行时间的比值。等待时间指进程处于等待处理机状态时间之和。对于交互式系统，更关心的是响应时间。
