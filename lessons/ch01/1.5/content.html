1. 什么是操作系统引导

定义

操作系统引导（Booting）是指计算机加电（或复位）后，通过一段引导程序，把操作系统的内核从磁盘装入内存并启动执行，从而把机器从「裸机」状态引导到操作系统可以工作的状态。

引导的本质：CPU 加电时内存中还没有操作系统，必须先运行一小段固化在 ROM 中的程序（BIOS/UEFI），再由磁盘上的引导程序把内核搬进内存并交给它执行。

2. 磁盘的分区结构与主引导记录

一块磁盘可以划分成若干分区，每个分区可安装不同的文件系统或操作系统。磁盘的第 0 号扇区（512 字节）称为主引导记录（MBR）。

关键结论：MBR 的三个组成部分

① 引导代码（引导程序）：位于磁盘 0 号扇区，负责查找并加载活动分区中的引导程序；

② 磁盘分区表（DPT）：记录各分区的位置与大小，共 4 个分区表项，每个 16 字节；

③ 结束标志：最后 2 个字节为 0x55AA，用于标识这是一个合法的 MBR。

  • 活动分区（引导分区）：分区表中被标记为可引导的那个分区，系统只从它的第一个扇区继续引导。
  • 分区引导记录（PBR / 引导扇区）：活动分区的第 1 个扇区，其中存放该分区的引导加载程序。

3. 操作系统的引导过程

引导流程（须按顺序背诵）

① 加电或复位，CPU 从固定地址取指，执行主板 ROM 中的 BIOS（或 UEFI），进行加电自检（POST）；

② BIOS 按设定的启动顺序找到启动磁盘，读取其 0 号扇区——MBR 并执行其中的引导代码；

③ MBR 中的引导代码扫描分区表，找到活动分区；

④ 读取活动分区的第一个扇区——分区引导记录 PBR，执行其中的引导加载程序；

⑤ 引导加载程序（如 GRUB）把操作系统内核从磁盘装入内存并跳转执行；

⑥ 内核完成初始化，创建第一个进程，操作系统开始运行。

记忆口诀

引导顺序：BIOS → MBR → 活动分区 → PBR → 引导加载程序 → 内核。

3.1 引导程序的接力关系

  • 一级引导（固件）：ROM 中的 BIOS/UEFI，负责硬件自检并按启动顺序找到启动磁盘。
  • 二级引导：磁盘上的 MBR 与 PBR 中的引导代码，负责定位并加载引导加载程序。
  • 引导加载程序：如 GRUB，负责把操作系统内核装入内存并跳转执行。

MBR 只有一个扇区（512 字节），容纳不下完整的引导逻辑，因此引导过程往往由多级引导程序接力完成。

易错点

① MBR 位于整块磁盘的 0 号扇区，而活动分区的第一个扇区是PBR，二者位置不同；

② 活动分区只是分区表中被标记为可引导的那一个分区，并非所有分区都能引导；

③ BIOS 做的是自检并读取 MBR，真正把内核装入内存的是引导加载程序（如 GRUB）。

6. 本节小结与真题问法

关键结论

MBR 三件套：引导代码 + 磁盘分区表（4 项，每项 16 字节）+ 结束标志 0x55AA。

引导链：BIOS/UEFI → MBR → 活动分区 → PBR（引导加载程序）→ 内核。

真题典型问法

① 问「引导过程的正确顺序」→ BIOS 自检 → 读 MBR → 找活动分区 → 读 PBR/引导加载程序 → 装入内核。

② 问「主引导记录包含什么」→ 引导代码、磁盘分区表（4 个分区项）、结束标志 0x55AA。

③ 给若干说法判断对错，通常错在：把「读 MBR」说成「直接读内核」／把 MBR 说成位于活动分区内。

教材原文（王道）

计算机的引导过程：CPU 执行 ROM 中的 BIOS，BIOS 读取启动盘的 0 号扇区（主引导记录 MBR），根据 MBR 中的分区表找到活动分区，再读取活动分区的第一个扇区，由其中的引导加载程序把操作系统内核装入内存。
