1. 操作系统是什么

定义

操作系统（Operating System, OS）是指控制和管理整个计算机系统的硬件与软件资源，合理地组织、调度计算机的工作与资源的分配，进而为用户和其他软件提供方便接口与环境的程序集合。它是计算机系统中最基本的系统软件。

把这个定义拆成三层来记，考试就好答了：

  • 管什么：管理硬件资源 + 软件资源（不是管「人」，也不只是管硬件）。
  • 怎么管：合理地组织、调度、分配资源（这是 OS 的核心动作）。
  • 管给谁用：为用户和其他软件提供方便接口与环境。
易错点

OS 是系统软件，不是应用软件，也不是「通用软件」。没有任何软件支持的计算机称为裸机；覆盖了软件层的机器称为扩充机器（虚拟机）。

2. 操作系统的四大特征

特征含义典型表现 / 技术
并发 两个或多个事件在同一时间间隔内发生（宏观同时、微观交替） 多个进程在一段时间内交替使用 CPU
共享 系统中的资源可供内存中多个并发进程共同使用 互斥共享（打印机）／同时共享（磁盘）
虚拟 把一个物理实体变成若干个逻辑上的对应物 时分复用（虚拟处理机、虚拟设备）／空分复用（虚拟存储器）
异步 进程以不可预知的速度向前推进 进程走走停停，何时执行、何时暂停不确定

2.1 共享的两种方式

  • 互斥共享方式：在一段时间内只允许一个进程访问该资源。例如打印机、某些变量。这类资源称为临界资源（独占资源）。
  • 同时共享方式：允许在一段时间内由多个进程「同时」（宏观）访问。注意：微观上仍然是交替访问的。例如磁盘、可重入代码。
关键结论

并发和共享是操作系统最基本的特征，二者互为存在条件：

① 没有并发，就谈不上共享（只有一道程序，无所谓共享）；② 没有共享，并发程序就无法正常推进（资源无法被多个进程使用）。

高频陷阱：并发 ≠ 并行

并发（Concurrence）：同一时间间隔内发生，微观上交替执行，单核即可实现。

并行（Parallelism）：同一时刻同时发生，必须多核（多处理机）硬件支持。

一句话：并发是「时间段」，并行是「时间点」；并行是并发在多核下的特例。

3. 操作系统的目标与功能

3.1 目标

方便性、有效性、可扩充性、开放性。其中方便性与有效性是最基本的两个目标。

3.2 功能：作为系统资源的管理者

四大管理

处理机管理（进程管理）、存储器管理（内存管理）、文件管理、设备管理。

3.3 功能：作为用户与硬件之间的接口

接口类型说明举例
命令接口供用户直接或间接控制作业联机命令界面（交互式）、脱机命令界面（批处理 .bat）
程序接口供程序在运行中请求 OS 服务系统调用（广义指令）

3.4 功能：作为扩充机器

OS 把裸机改造成功能更强、使用更方便的「扩充机器」或「虚拟机」——用户无需了解硬件细节即可使用计算机。

4. 本节小结与真题问法

记忆口诀

四特征：并发、共享、虚拟、异步（「并共虚异」）。

最基本的两个：并发、共享，互为存在条件。

四大管理：处理机、存储器、文件、设备。

两类接口：命令接口、程序接口（系统调用）。

真题典型问法

① 问「操作系统的四大特征中最基本的是」→ 答并发和共享。

② 问「单处理机能否实现并发」→ 能（并发是时间间隔内的宏观同时、微观交替）。

③ 给若干说法判断对错，通常错在：把 OS 说成应用软件／把并发说成同一时刻／把系统调用说成命令接口。
