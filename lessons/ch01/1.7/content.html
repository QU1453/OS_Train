2. 逐节核心速记

2.1 概念与发展

  • 本质：OS 是系统软件，兼具资源管理者、用户与硬件的接口、扩充机器三重身份。
  • 最基本特征：并发与共享，二者互为存在条件。
  • 并发 ≠ 并行：并发是「时间间隔」（单核可行），并行是「同一时刻」（需多核）。
  • 分时 OS：多路性、独立性、及时性、交互性；实时 OS：及时性与可靠性（可靠性往往最关键）。

2.2 运行环境

分类来源典型例子处理位置
中断（外中断）CPU 外部事件I/O 完成中断、时钟中断内核态
异常（内中断/陷入）CPU 内部执行指令系统调用（trap）、缺页（故障）、除零、终止内核态
  • 特权指令只能在内核态执行；用户态执行特权指令会引发异常而转入内核态。
  • 用户态 → 内核态：通过中断/异常/系统调用；内核态 → 用户态：执行特权指令修改程序状态字（PSW）。
  • 系统调用由用户程序在用户态发起，但其执行在内核态。

2.3 结构与引导

对比项宏内核（单内核）微内核
内核范围几乎所有系统功能都在内核态仅保留最基本功能在内核态
典型置于内核进程、内存、文件、设备管理等进程管理、中断处理、进程通信等
优点性能高（切换少）可靠、可扩展、可移植
缺点庞大、难维护、可靠性低用户态/内核态频繁切换，性能开销大

引导大致顺序：加电 → BIOS/UEFI 自检 → 读取主引导记录（MBR）/引导扇区 → 执行引导加载程序 → 装入并启动操作系统内核。

3. 高频易错点清单

  1. 特征：并发与共享是最基本特征；「虚拟」分时分复用（虚拟处理机、虚拟设备）与空分复用（虚拟存储器）。
  2. 并发/并行：并发是宏观同时、微观交替，单处理机即可；并行必须多处理机。
  3. 中断与异常：中断来自 CPU 外部，异常来自 CPU 内部；系统调用属于异常（内中断）。
  4. 特权指令：只能在内核态执行，如关中断、置时钟、修改 PSW 等。
  5. 系统调用：在用户态发起、在内核态执行，属于程序接口。
  6. 内核态 ↔ 用户态：进入内核态靠中断/异常；返回用户态靠特权指令。
  7. 宏/微内核：微内核把文件系统、设备管理等移到用户态，换来可靠性却牺牲性能。
  8. 虚拟机：第一类站硬件、第二类站宿主 OS；虚拟化有性能开销，不是「零成本」。

4. 真题精讲

真题 1（运行环境）

题：下列选项中，不可能在用户态发生的事件是（　）。

A. 系统调用　B. 外部中断　C. 进程切换　D. 缺页

答案：C

解析：系统调用由用户程序在用户态主动发起；外部中断可打断正在用户态执行的程序，因而可在用户态「发生」；缺页属故障异常，可由用户态指令触发。而进程切换只能由内核（内核态）完成，不可能在用户态发生，故选 C。

真题 2（中断与异常）

题：下列关于中断和异常的叙述中，正确的是（　）。

A. 中断和异常都来自 CPU 内部　B. 系统调用属于中断

C. 缺页属于异常　D. 中断处理程序运行在用户态

答案：C

解析：中断来自 CPU 外部、异常来自 CPU 内部，A 错；系统调用属于异常（内中断/trap）而非中断，B 错；缺页是典型的故障型异常，C 对；中断/异常处理程序均运行在内核态，D 错。

真题 3（操作系统结构）

题：在微内核操作系统中，下列功能通常不放在微内核里、而是放到用户态实现的是（　）。

A. 进程管理　B. 进程间通信　C. 中断处理　D. 文件系统管理

答案：D

解析：微内核只保留最基本的功能——进程（线程）管理、低级存储器管理、中断与陷入处理、进程间通信等；而文件系统、设备管理、命令解释器等以服务器形式放在用户态实现，以提高可靠性与可扩展性。故选 D。

真题 4（虚拟机）

题：下列软件中，属于第二类虚拟机管理程序的是（　）。

A. Xen　B. VMware ESXi　C. VirtualBox　D. Microsoft Hyper-V

答案：C

解析：第二类 VMM 运行在宿主操作系统之上，是宿主 OS 上的应用程序，如 VMware Workstation、VirtualBox；A、B、D 直接运行在裸机硬件上，属于第一类（裸金属型）。故选 C。

本章复习要诀

判断题抓「态」（内核态/用户态）、「源」（内/外）、「层」（VMM/微内核），这三处最容易设陷阱。
